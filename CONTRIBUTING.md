# Contributing

First off, thanks for taking the time to contribute!

The goal of this project is to collect the best **free** and **open-source** alternatives to paid software.

## Guidelines

To ensure the list stays high-quality, please follow these rules:

1. **Free Tier:** The tool must have a genuinely useful "Free" tier. (No 7-day trials).
2. **Open Source:** Prefer open-source tools. If not open-source, ensure it's trustworthy and widely used.
3. **Relevant:** Please add the tool to the most appropriate category.

## How to Add a Tool

1. Fork this repository.
2. Create a new branch (`git checkout -b add-tool-name`).
3. Copy the template below and fill in the details.
4. Add it to the bottom of the relevant category table in `README.md`.
5. Commit your changes and open a Pull Request!

### Copy-Paste Template

Please use this format to keep the tables consistent:

```markdown
| **[Tool Name](https://link-to-tool.com)** | Short description of what it does. | Free | Yes / No | No / Optional / Required |
```

Legend:

- Pricing: Free or Free (Ads) or Freemium

- Open Source: Yes or No

- Account? No, Optional, or Required
